## Переклад каталогу інструментів маховика

### 1) NTM — Named Tmux Manager

- Теглайн: **Оркестрація `tmux` для багатьох агентів**.
- Ключові можливості:
  - Паралельний запуск 10+ агентів Claude/Codex/Gemini.
  - Розумне широкомовне надсилання з фільтрацією за типом, варіантом і мітками.
  - Анімована панель стану 60 кадрів/с з наглядом за здоров'ям.
- Зв'язки:
  - `slb`: небезпечні команди проходять перевірки безпеки.
  - `mail`: повідомлення Overseer і резервування файлів.
  - `cass`: виявлення дублікатів і пошук історії сеансів.
  - `bv`: панель показує стан задач `beads`; `--robot-triage` для розподілу.

### 2) SLB — Simultaneous Launch Button

- Теглайн: **Взаємна перевірка небезпечних команд**.
- Можливості:
  - Триступенева класифікація ризику (`CRITICAL/DANGEROUS/CAUTION`).
  - Криптографічне зв'язування команд (`SHA256 + HMAC`).
  - Динамічний кворум за активними агентами.
- Зв'язки:
  - `mail`: сповіщення надсилаються у вхідні скриньки рецензентів.
  - `ubs`: передзапускова перевірка коду.

### 3) Mail — MCP Agent Mail

- Теглайн: **Обмін повідомленнями і координація між агентами**.
- Можливості:
  - Повідомлення між агентами у форматі Markdown.
  - Дорадче резервування файлів для уникнення конфліктів.
  - Сховище на SQLite для повного перевірного сліду.
- Зв'язки:
  - `bv`: ідентифікатори задач поєднують обговорення з задачами `beads`.
  - `cm`: спільний контекст між сеансами.
  - `slb`: запити на погодження потрапляють у вхідні.

### 4) BV — Beads Viewer

- Теглайн: **Графова аналітика для залежностей задач**.
- Можливості:
  - 9 графових метрик: `PageRank`, посередництво, критичний шлях тощо.
  - Протокол робота (`--robot-*`) з JSON-виводом для агентів.
  - Відображення TUI на 60 кадрів/с через `Bubble Tea`.
- Зв'язки:
  - `mail`: оновлення задач породжують поштові сповіщення.
  - `ubs`: результати сканера помилок створюють блокувальні задачі.
  - `cass`: пошук попередніх сеансів для контексту задач.

### 5) UBS — Ultimate Bug Scanner

- Теглайн: **Виявлення помилок за шаблонами**.
- Можливості:
  - 1000+ шаблонів виявлення для різних мов.
  - Єдиний JSON-формат результатів.
  - Придатний для `pre-commit` та конвеєрів безперервної інтеграції.
- Зв'язки:
  - `bv`: створює задачі за знайденими дефектами.
  - `slb`: перевіряє код перед ризикованими комітами.

### 6) CM — CASS Memory System

- Теглайн: **Тривала пам'ять між сеансами**.
- Можливості:
  - Тришарова когнітивна пам'ять: епізодична, робоча, процедурна.
  - Інструменти MCP для збереження контексту між сеансами.
  - Побудовано поверх CASS для семантичного пошуку.
- Зв'язки:
  - `mail`: зберігає резюме розмов для подальшого відтворення.
  - `cass`: семантичний пошук по збереженій пам'яті.
  - `bv`: пам'ятає шаблони задач і рішень.

### 7) CASS — Coding Agent Session Search

- Теглайн: **Єдиний пошук по 11+ форматах сеансів агентів**.
- Можливості:
  - Підтримка 11 форматів: Claude Code, Codex, Cursor, Gemini, ChatGPT, Aider тощо.
  - Кешований пошук менш ніж за 5 мс, гібрид семантики і ключових слів.
  - Синхронізація між машинами через SSH з відображенням шляхів.
- Зв'язки:
  - `cm`: CM використовує CASS для добування пам'яті.
  - `ntm`: виявлення дублікатів перед масовими розсиланнями.
  - `bv`: пов'язування результатів пошуку із задачами.
  - `mail`: агенти перевіряють історію перед зверненням до колег.

### 8) ACFS — Flywheel Setup

- Теглайн: **Підготовка середовища однією командою**.
- Можливості:
  - Налаштування "з нуля до результату" приблизно за 30 хвилин.
  - Встановлення Claude Code, Codex і Gemini CLI.
  - Попередньо налаштований увесь набір інструментів маховика.
- Зв'язки:
  - `ntm`: встановлює і налаштовує NTM.
  - `mail`: піднімає MCP-сервер Agent Mail.
  - `dcg`: встановлює запобіжні гачки DCG.

### 9) DCG — Destructive Command Guard

- Теглайн: **Перехоплення руйнівних команд оболонки**.
- Можливості:
  - Перехоплює `rm -rf`, `git reset --hard` тощо.
  - Прискорене зіставлення шаблонів на SIMD.
  - Журнал аудиту виконаних команд.
- Зв'язки:
  - `slb`: працює разом зі SLB як багатошаровий захист.
  - `ntm`: захищає команди в сеансах під керуванням NTM.

### 10) RU — Repo Updater

- Теглайн: **Синхронізація багатьох репозиторіїв однією командою**.
- Можливості:
  - Єдиний виклик для синхронізації кількох репозиторіїв.
  - Паралельні дії з виявленням конфліктів.
  - Інтеграція перевірки коду агентами.
- Зв'язки:
  - `ubs`: запуск сканувань помилок у всіх синхронізованих репозиторіях.
  - `ntm`: інтеграція для агентних масових проходів.

### 11) GIIL — Get Image from Internet Link

- Теглайн: **Завантаження зображень із посилань спільного доступу**.
- Можливості:
  - Підтримка публічних посилань iCloud.
  - Завантаження зображень через CLI.
  - Працює через SSH без графічного інтерфейсу.
- Зв'язки:
  - `mail`: завантажені зображення можна вкладати у листування Agent Mail.
  - `cass`: сеанси аналізу зображень доступні для пошуку.

### 12) XF — X Archive Search

- Теглайн: **Надшвидкий пошук по архіву X/Twitter**.
- Можливості:
  - Пошук великими архівами за частки секунди.
  - Гібридний пошук: семантика + ключові слова.
  - Локальна обробка зі збереженням приватності.
- Зв'язки:
  - `cass`: подібна архітектура і підходи пошуку.
  - `cm`: знайдені дописи можуть ставати одиницями пам'яті.

### 13) s2p — Source to Prompt TUI

- Теглайн: **Поєднання вихідних файлів у підказки для мовних моделей**.
- Можливості:
  - Інтерактивний вибір файлів у TUI.
  - Підрахунок токенів у реальному часі.
  - Фільтрація з урахуванням `gitignore`.
- Зв'язки:
  - `cass`: згенеровані підказки можна знаходити пізніше.
  - `cm`: ефективні підказки зберігаються як пам'ять.

### 14) MS — Meta Skill

- Теглайн: **Керування навичками з відстеженням результативності**.
- Можливості:
  - MCP-сервер для нативної інтеграції агентів.
  - Підказки оптимізуються методом вибірки Томпсона.
  - Багатошаровий захист (`ACIP`, `DCG`, політика шляхів).
- Зв'язки:
  - `cass`: одне з джерел для видобування навичок.
  - `cm`: навички та пам'ять CM — взаємодоповнювані шари.
  - `bv`: графовий аналіз залежностей навичок.
