# Системні сторінки та стани помилок

## `app/not-found.tsx` (404)

- `Path not found. The requested route does not exist in the site map.` →
  **Шлях не знайдено. Запитаний маршрут відсутній у мапі сайту.**
- Кнопка `Return Home` → **Повернутися на головну**.

## `app/error.tsx` (помилка маршруту)

- Заголовок `Something went wrong` → **Щось пішло не так**.
- Опис `An unexpected error occurred. Try refreshing the page.` →
  **Сталася неочікувана помилка. Спробуйте оновити сторінку.**
- Кнопка `Try Again` → **Спробувати знову**.

## `app/global-error.tsx` (глобальна помилка)

- Заголовок `System Fault` → **Системний збій**.
- Мітка `Digest:` → **Відбиток:**
- Кнопка `Try again` → **Спробувати знову**.
